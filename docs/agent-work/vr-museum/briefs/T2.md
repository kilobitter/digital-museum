## Context and exact contracts
Reuse `parseMuseum`, `defaultMuseum`, `closestPointOnSegment`, `wallNormal`, `wallLength`,
`workPlacement`, `distanceInside` from `src/shared/*`. Do not modify `src/shared/museum.ts`.
Coordinate convention (from museum.ts): plan +x right, plan +y DOWN on screen. Draw the SVG with
plan coordinates directly (y down), so no flip is needed.

Dev API — implement as a Vite plugin with `apply: 'serve'` in `src/devserver/museumApi.ts`,
registered in `vite.config.ts`. Put request-independent logic (path checks, id/extension choice,
atomic write, loopback check) in pure/testable functions that take the museum root dir as a param.
Museum root = `<project>/public/museum`.

```
PUT    /api/museum                      body: Museum JSON (≤ 5 MB)
  -> 200 {ok:true} | 400 {ok:false, errors:string[]}   (server re-validates with parseMuseum)
  write museum.json atomically: write museum.json.tmp-<rand> in same dir, then rename.
POST   /api/media?name=<original filename>   body: raw bytes (≤ 50 MB)
  -> 200 {file:"media/<id>.<ext>"} | 400 {error} | 413 {error}
  ext from the original name, lower-cased, must be in: jpg jpeg png webp mp3 m4a aac ogg wav
  id = server-generated, [a-z0-9]{10}; never use the client name in the path.
DELETE /api/media?file=media/<id>.<ext>
  -> 200 {ok:true} | 400 {error} | 404 {error}
  file must match /^media\/[A-Za-z0-9_-]+\.(jpg|jpeg|png|webp|mp3|m4a|aac|ogg|wav)$/ exactly;
  resolve and assert the result is inside <root>/media before unlinking.
```
Request guards, applied to every `/api/*` request, in this order:
1. Remote address must be loopback (`127.0.0.1`, `::1`, `::ffff:127.0.0.1`) → else 403.
   (The dev server is LAN-exposed for Quest preview; only the editor's own machine may write.)
2. Header `X-Museum-Editor: 1` required → else 403. (Forces a CORS preflight, which Vite does not
   approve, so other websites open in the same browser can't write via a simple cross-origin POST.)
3. If an `Origin` header is present, its host must equal the request `Host` → else 403.
Unknown method/path under `/api/` → 404/405 JSON. Body over limit → 413 without buffering it all.

Vite reload: configure `server.watch.ignored` (or equivalent) so writes under `public/museum/**`
don't cause a full reload of open pages.

Allowed new dependencies: `react`, `react-dom`, `@types/react`, `@types/react-dom`,
`@vitejs/plugin-react`, `@types/node`. Current stable versions. No others without stopping.
Plain CSS; no UI component library, no state library (useReducer/context or a tiny store is fine).
