### A. Pure model functions (new module(s) in `src/editor/`, unit-tested)
A selection is a set of references: walls, works, zones, areas, and optionally the spawn. Shape is yours
(e.g. `{ walls: string[]; works: string[]; zones: string[]; areas: string[]; spawn: boolean }`).
- `itemsInRect(museum, rect, opts)` — everything **fully inside** the rect: wall = both endpoints;
  work = both ends of its plan segment (`workSegment` in hit.ts); rect zone = its rect; circle zone =
  its bounding square; area = its rect; spawn = its point. `opts` chooses which kinds are eligible.
- `moveSelection(m, sel, delta)` — translates selected walls (both endpoints), zones, areas, spawn.
  Works ride along with their walls automatically (they are wall-relative); selected works whose wall
  is not selected are left where they are. Unselected walls that shared an endpoint are not dragged
  along (they detach) — state this in the hint text.
- `rotateSelection(m, sel, dir: 1 | -1)` — 90° about the selection's bounding-box centre, the centre
  snapped to the grid so grid-aligned plans stay grid-aligned. Walls: rotate both points (works keep
  `side`, `t`, size — they rotate with the wall). Rect zones / areas: rotate the rect (w/h swap, new x/y).
  Circle zones: rotate centre. Spawn: rotate point and add ∓90 to `yawDeg` consistently with the plan's
  coordinate convention (plan +y is down on screen; `yawDeg` 0 faces plan −y; check
  `src/shared/geometry.ts`). Rotating 4× returns the identical museum (test), and the visual direction
  matches the button (CW on screen for the "clockwise" button — test with a concrete point).
- `duplicateSelection(m, sel, offset)` — copies with fresh ids (use `newId`); duplicated walls also
  duplicate all works on them (whether or not those works were selected); zones/areas/selected works on
  unselected walls are copied too (a lone work copy is offset along its wall only if it still fits,
  otherwise skipped). Returns the new museum and the selection of the copies. Spawn is never duplicated.
- `deleteSelection(m, sel)` — deletes all; works on deleted walls go too (as `deleteWall` does today).
- `setFinishForWalls(m, wallIds, finish | undefined)` — batch wall finish (undefined = use default).
- `cutDoorway(m, wallId, centreT, width)` — splits the wall into two walls leaving a gap of `width`
  centred at `centreT` (metres from `a`). Rules:
  - The gap is clamped inside the wall. If a remaining piece would be shorter than 0.15 m, that piece
    is dropped (the gap extends to that end) — no slivers.
  - If the wall is not longer than `width`, return an error ("This wall is shorter than the door").
  - The first piece keeps the original wall id; the second gets a new id; both keep the wall's `finish`.
  - Works fully on a piece stay on it (second piece: `t` re-based to its own `a`). Works overlapping
    the gap (any part of `t ± width/2` inside it) are removed and returned as `removedWorks` so the UI
    can say "1 painting was taken down to make room for the door".
  - Zones and areas are untouched.
  Tests: centred door; door near one end drops the sliver; door wider than wall → error; works on both
  sides land on the right piece with correct `t`; overlapping work removed; finish preserved; ids unique.

### B. Selection UI (`Canvas.tsx`, `App.tsx`, `Inspector.tsx`, styles)
- With the Select tool, **dragging on empty canvas draws a selection box** (dashed accent rectangle);
  release selects everything fully inside. Plain click on empty canvas still clears the selection.
  Panning stays Space+drag / middle mouse (unchanged).
- **Shift+click** toggles an item in/out; **Shift+box** adds to the selection.
- **Ctrl/Cmd+A** selects all eligible items in the current layer. **Esc** clears (after cancelling a draft, as today).
- Layers: in **Build**, eligible = walls, works, zones, spawn, and — with the **"Include areas"** toggle
  (default on, remembered in localStorage, try/catch) — areas fully inside the box (drawn highlighted even
  though areas are faint in Build). Single clicks in Build still never pick areas. In **Areas** layer the
  box and Shift-click select areas only.
- Selected items are highlighted the same way single selection is today. One item selected = today's
  single-item behaviour and inspector, unchanged (handles, endpoint drag, resize etc.). With **two or
  more**, endpoint/resize handles are hidden; dragging any selected item moves the whole group, delta
  snapped to the grid (same snapping rules/modifiers as moving a single item today). A drag is one undo
  step, autosave pauses during it (existing `interacting` mechanism).
- **Arrow keys** nudge the selection by one grid step (Shift: 5 steps); a burst of nudges may be one
  undo step or several — your choice, say which.
- **Rotate**: `[` = counter-clockwise, `]` = clockwise (on screen), plus buttons in the multi inspector.
  Works for a single selected wall/zone/area too.
- **Ctrl/Cmd+D** duplicates the selection (offset +1 m, +1 m, snapped), selects the copies. Keep the
  existing area duplicate behaviour working (it becomes the same path).
- **Delete/Backspace** deletes the selection (one undo step).
- **Multi inspector** (2+ items): counts per kind ("12 walls, 30 paintings, 2 zones, 3 areas"),
  buttons Rotate ⟲ / ⟳, Duplicate, Delete, the "Include areas" toggle, and — when walls are selected —
  a wall finish editor applying to all selected walls (reuse the finish editor; show that values are
  mixed when they differ; "Use default finish" option). Hint line explaining Shift-click, box select,
  arrows, `[` `]`.
- Performance: box select and group drag stay smooth with the stress museum (~500 works, ~300 walls):
  don't re-run hit tests for every item per pointer move beyond what's needed; group-drag preview may
  apply `moveSelection` per move (it's cheap) but must not push history per move.
