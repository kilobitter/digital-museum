## Goal and non-goals
An area can set a room height. The ceiling there sits at that height, walls grow to match, and any step between neighbouring ceilings is closed so no hole shows. Works end to end: schema, editor, viewer, import, painting validation.

Non-goals: per-wall manual heights; sloped ceilings; non-rectangular areas; floors at different levels; changing how paintings are placed (`centerHeight` stays absolute); changes to collision, XR, streaming or sealing; a `MUSEUM_VERSION` bump.

## Done when
- A museum where no area has `roomHeight` builds exactly what it built before: one profile piece per wall at `wallHeight`, `wallPieces` matching `wallSpans` (same from/to/caps, no steps), no ceiling steps, gradients unchanged.
- Two rooms of 3 m and 5 m sharing a wall: the shared wall is 5 m, each ceiling at its own height, no gap.
- A doorway in that shared wall has a panel above it from 3 m to 5 m, visible from the tall room.
- Two areas of different height with no wall between them get a panel across the whole boundary. With `settings.ceiling` false, or next to open sky, no panel is made.
- A panel never coincides with a wall that covers it (see "Ceiling steps").
- A wall that crosses several areas changes height along its length, and every exposed step in it has an end face (see "Wall pieces").
- Painting checks use the room on the side the painting hangs on: a 3.5 m-tall painting on the 3 m side of a 5 m wall is flagged `above-wall`.
- Import: a guest with a different `wallHeight` keeps its height (see "Import merge").
- `roomHeight` round-trips through `parseMuseum`; zero, negative or non-numeric values give an error at `areas[i].roomHeight`; an area with only `roomHeight` is valid.
- `npm test` and `npm run build` pass.

## Context and exact contracts

### Heights: new `src/shared/roomHeights.ts` (pure, no three.js)
```ts
export function roomHeightAt(m: Museum, x: number, y: number): number;
// Top-most (last) area with roomHeight strictly containing (x,y), else settings.wallHeight.

export interface WallHeightPiece { from: number; to: number; plus: number; minus: number; top: number }
export function wallHeightProfile(m: Museum, wall: Wall): WallHeightPiece[];
// Pieces cover t in [0, wallLength] in order, with no gaps. plus/minus = room height on the +perp(d) / -perp(d)
// side, sampled at settings.wallThickness/2 + 0.01 m from the centre line, at the middle of each interval.
// top = max(plus, minus). Break where either sample line crosses an edge of an area that has roomHeight, for any
// wall angle; merge neighbours with equal plus and minus; drop slivers under 1e-4 m.
// Zero-length wall: one piece [0,0] sampled at the point. No area has roomHeight: one piece (fast path).

export function wallTopAt(profile: WallHeightPiece[], t: number): number; // t clamped to the profile
export function wallSideHeight(m: Museum, wall: Wall, side: WallSide, from: number, to: number): number;
// Lowest room height on that face over [from, to], clamped to the wall.
```
Perp and side follow `museum.ts` (`perp(d) = (-d.y, d.x)`, side 1 = +perp).

### Ceiling: `src/viewer/surfaces.ts`
`decomposeCeiling(bounds, base, areas, baseHeight)`. `baseHeight` is required; update callers and tests.
- Grid edges come from areas with `ceiling`, `openSky` or `roomHeight`. Each cell resolves the finish or open sky as today, and its height independently, as stated in `museum.ts`.
- `CeilingGroup` gains `height: number`. Cells merge only with equal finish and height. Keep the "base finish first" order.
- `CeilingPlan` gains `steps: CeilingStep[]`:
```ts
export interface CeilingStep {
  a: Vec2; b: Vec2;        // plan end points on the shared cell edge, axis-aligned
  bottom: number; top: number; // the two ceiling heights
  finish: Finish;          // finish of the LOWER ceiling
  normal: Vec2;            // unit plan normal pointing at the TALLER side
}
```
One step per run of cell edges where both cells have a ceiling and heights differ by more than 1e-6. Merge collinear touching runs with equal bottom, top, finish and normal. No step on the outer edge of `bounds`, and none next to an open cell.

New in `surfaces.ts`:
```ts
export function stepQuad(step: CeilingStep): THREE.BufferGeometry;
// Single-sided vertical quad facing `normal`, same attributes and index as surfaceQuad so it merges with ceiling
// quads. World-scale UVs: u = along-the-edge world coordinate / tileSize, v = height / tileSize.
export function uncoveredSteps(steps: CeilingStep[], walls: readonly Wall[], spans: Map<string, WallSpan[]>, thickness: number): CeilingStep[];
// Cuts away the parts of each step covered by a parallel, axis-aligned wall whose centre line is within
// thickness/2 + 1e-6 of the step's line, using the wall's drawn spans (extensions included). A wall that does not
// cover it, or a diagonal wall, leaves the step alone. Drop remainders under 1e-4 m.
```

### Wall pieces: `src/viewer/wallJoints.ts`
```ts
export interface WallPiece extends WallSpan { top: number; stepFrom: number | null; stepTo: number | null }
export function wallPieces(walls: readonly Wall[], spans: Map<string, WallSpan[]>, profiles: Map<string, WallHeightPiece[]>, thickness: number): Map<string, WallPiece[]>;
```
- Each span is cut at the profile's breaks. Extensions past the wall's end points (from < 0, to > length) take the height of the nearest profile piece.
- `stepFrom`/`stepTo` = height where a partial end face starts, running up to `top`; null when none is needed. `capFrom`/`capTo` keep meaning a full end face. A piece never has both on one end.
- Inside a wall, at a height break: the taller piece gets a step starting at the shorter piece's top. Cuts between pieces have no full caps.
- At a true wall end (the `a` or `b` end) with no full cap, work out `cover`, the highest of:
  - each wall joined end-to-end there: that wall's `wallTopAt` at its touching end;
  - each wall forming a T there: the lowest top of that wall over `[s - thickness/2, s + thickness/2]`, where `s` is the junction's position along it.
  Use the same joint tests and tolerances as `endAt` (skip overlapping collinear walls). If `top > cover + 1e-6`, the step starts at `cover`.
- Ends cut by `wallSpans` overlap handling stay open: the later wall sits at the same place and has the same height.

### Wall geometry: `src/viewer/wallGeometry.ts`
- `wallGeometry` also takes optional partial end faces: `steps: { start?: number | null; end?: number | null }`, in world height. These are appended to the box with the same attributes, so the geometry still merges. They face outward like the matching full cap, with UV v = world height / tileSize. Omitted steps must give the same output as today.
- `applyWallGradient(geo, height, bottomHex, topHex, gradientHeight = height)`: t = (localY + height/2) / gradientHeight, clamped. Vertices of partial faces get colours too.

### Scene: `src/viewer/scene.ts`
- Walls: profiles → `wallPieces`. Each piece is a box of height `top`, centred at y = top/2. Keep the existing per-wall UV offsets (`lo`/`hi` from the wall's spans) so tiling stays continuous.
- Gradient height for a wall = the highest `top` of any of its pieces, so colour is continuous along the wall.
- Ceiling quads use `grp.height`. When `settings.ceiling` is on, add `uncoveredSteps(plan.steps, ...)` via `stepQuad` to the same per-material ceiling list. Keep draw calls per material, not per room.
- Walls follow `roomHeight` whether or not ceilings are on.
