## Goal
A wall finish can be a top–bottom colour gradient: `color` at the floor → `colorTop` at the top of
the wall. Only vertical, no rotation. Walls only (default wall finish, per-wall finish, batch wall
finish); floor/ceiling finishes and areas don't get it.

## Done when
### A. Validation (`src/shared/validate.ts` + tests)
- `colorTop` accepted on `settings.wallFinish` and `walls[].finish` only; must be `#rrggbb`. Present on
  a floor/ceiling/area finish → error. Format stays v4 (additive, optional). Round-trip tests.

### B. Viewer (`src/viewer/**`)
- Walls with a gradient finish: per-vertex colours on the wall geometry, interpolated by height
  (0 → `color`, wallHeight → `colorTop`); the top cap is `colorTop`. Material uses `vertexColors` with a
  white base colour, still multiplied with the texture map when present. Convert the hex colours the
  same way three.js converts material colours (sRGB → linear working space) so a gradient whose two
  ends are equal looks identical to the plain-colour wall of that colour (test that conversion helper).
- Walls stay merged per finish: include `colorTop` in the merge key (`finishKey` or the wall-specific
  key); uniform walls unchanged. No extra draw calls beyond one per distinct finish, as today.

### C. Editor (`src/editor/**`)
- In the wall finish editors (settings default wall finish, single-wall inspector, multi-wall batch
  finish incl. its "mixed" handling): a **Gradient** checkbox. Off = today's single colour. On = two
  colour pickers labelled **Top** and **Bottom** (Bottom is `color`), with a small vertical preview
  swatch (top colour at the top). Turning it on starts with `colorTop` = current colour; turning it off
  removes `colorTop`. Floor/ceiling/area finish editors don't show the checkbox.
- `importMerge.ts` `sameFinish` (and any other finish equality, e.g. "mixed" detection) compares
  `colorTop` too. Blueprint wall colouring unchanged.

### D. Sample + README
- Sample museum: one wall with a gradient finish. README: one line in the wall finish section.
