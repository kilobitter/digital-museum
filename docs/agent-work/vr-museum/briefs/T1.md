## Context and exact contracts
Data contract: `src/shared/museum.ts` (read it; do not modify). Note the coordinate mapping
and the `side` / `yawDeg` definitions in its comments.

Create these shared modules with **exactly** these exports (more internal helpers are fine);
the editor (T2) will import them:

```ts
// src/shared/validate.ts
export function defaultMuseum(): Museum; // empty museum, version 1, settings defaults from museum.ts comments, spawn {x:0,y:0,yawDeg:0}
export function parseMuseum(json: unknown):
  | { ok: true; museum: Museum }
  | { ok: false; errors: string[] };
// Checks: shape & types; finite numbers; positive wallHeight/wallThickness/gridSize, width, rect w/h, circle r;
// volume in [0,1]; fade >= 0; side is 1 or -1; unique ids per collection; Work.wallId exists;
// Work.mediaId -> image media; AudioZone.mediaId -> audio media; images have width/height;
// MediaItem.file matches /^media\/[A-Za-z0-9_-]+\.(jpg|jpeg|png|webp|mp3|m4a|aac|ogg|wav)$/;
// zero-length walls rejected. Unknown extra fields: ignore (don't fail). Errors are human-readable
// with a path, e.g. "works[2].wallId: no wall with id 'w9'".

// src/shared/geometry.ts
export function wallLength(w: Wall): number;
export function wallDirection(w: Wall): Vec2;                 // unit vector a->b
export function wallNormal(w: Wall, side: WallSide): Vec2;    // unit, = side * perp(dir), perp(d)=(-d.y,d.x)
export function closestPointOnSegment(p: Vec2, a: Vec2, b: Vec2): { point: Vec2; t: number; dist: number }; // t in metres from a, clamped
export function workPlacement(wall: Wall, work: Work, wallThickness: number): { center: Vec2; normal: Vec2 }; // centre on the wall FACE (segment point + normal * thickness/2)
export function yawToRotationY(yawDeg: number): number;       // radians for three.js Object3D.rotation.y

// src/shared/zones.ts
export function distanceInside(shape: ZoneShape, p: Vec2): number; // >0 inside = distance to nearest edge; <=0 outside
export function zoneGain(zone: AudioZone, p: Vec2): number;          // 0 outside; volume*smoothstep(0,1,d/fade) inside; fade 0 => volume when inside
```

Viewer code goes under `src/viewer/`. Keep collision and teleport-target validation as pure
functions (e.g. circle-vs-thick-segments with sliding; "is this floor point valid and is the
straight line from the player to it not crossing a wall") so they are unit-tested.

Sample museum: write `scripts/make-sample.mjs` (Node, **no extra deps**) that generates into
`public/museum/`: a `museum.json` with two connected rooms (doorway gap), 5–6 works on several

doorway area), a sensible spawn; placeholder raster images (e.g. distinct coloured/gradient PNGs
encoded with Node's built-in zlib; must be png/jpg/webp per the file regex) with differing
aspect ratios; and
2 short looping audio files (e.g. generated sine/chord WAVs, a few seconds). The generated
`museum.json` must pass `parseMuseum` (add a test that loads it).
