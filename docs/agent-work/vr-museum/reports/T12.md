# T12 report: vertical gradient for wall finishes

STATUS: ready_for_review

## Changes
- src/shared/validate.ts: `finish()` takes a `wall` flag. `colorTop` (#rrggbb) accepted on `settings.wallFinish` and `walls[].finish`; on floor/ceiling/area finishes it is an error ("a gradient is only allowed on wall finishes"). Still v4.
- src/viewer/wallGeometry.ts: `applyWallGradient(geo, height, bottomHex, topHex)` writes per-vertex `color` by local height (top cap = top colour); uses `new THREE.Color(hex)` so sRGB to linear matches material colours.
- src/viewer/surfaces.ts: `wallFinishKey` = `finishKey` + lowercase `colorTop`.
- src/viewer/scene.ts: walls keyed by `wallFinishKey`; gradient walls get material `{color: 0xffffff, vertexColors: true, map}` and the colour attribute. Still one mesh/draw call per distinct finish. Surfaces untouched.
- src/editor/model.ts: `withGradient(f, on)` (on: colorTop = current colour; off: removed).
- src/editor/Inspector.tsx: `FinishFields` has a `gradient` prop (set only for default wall finish, single-wall, multi-wall). Gradient checkbox; when on, Top and Bottom pickers (Bottom = `color`, the single Colour picker is hidden) plus a vertical preview swatch. Floor/ceiling/area editors unchanged.
- src/editor/MultiInspector.tsx: "gradient" added to the differs hint.
- src/editor/importMerge.ts: `sameFinish` compares `colorTop` (case-insensitive); `remapFinish` already keeps it.
- src/editor/styles.css: `.gradient-row`, `.gradient-preview`.
- scripts/make-sample.mjs (+ test): wall `wB-right` has gradient `#e8d5c4` to `#5b6c8f`. README: one wall-finish line.
- Tests added: validate (round-trip, bad values, floor/ceiling/area rejection), wallGeometry (gradient ends, top cap, linear, sRGB conversion with equal ends = plain colour), wallFinishKey, sameFinish/merge bake, withGradient, sample.
