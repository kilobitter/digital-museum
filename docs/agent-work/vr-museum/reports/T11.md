## Decisions and remaining risks
- Decisions: media map is a `Map`. Ceiling handling (open-sky base area, stripping guest area ceilings, baking a differing ceiling) applies only when the host has ceilings on, since otherwise nothing is visible. Placement x offset is rounded up to the grid so the gap is at least 2 m. Default wall/floor textures count as "used" for onlyUsed; the guest sky never does. Unreadable/oversized source files are treated as missing (warning) rather than upload failures.
- Dedupe is by `file` path + kind only; unrelated museums that happen to share names like `media/a.png` would wrongly be matched (as specified).
- Unverified in a real browser: the popover and file/folder pickers (incl. `webkitdirectory` fallback), real folder-handle reads, object-URL download, `fit()` framing after import, toast/panel appearance, and DecompressionStream on a real OS-made zip (tested only with zips from our writer, hand-built deflate entries and a fake dir handle).
- Import is not blocked from edits made while uploads run; the merge uses the latest museum and a `parseMuseum` check before applying.
