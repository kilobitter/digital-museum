## Correction 1
STATUS: ready_for_review
1. Autosave mid-gesture: Canvas has a new `onInteraction(active)` prop. It is set true at the pointerdown that starts a drag, resize, spawn placement or room/zone draft, and false on commit, cancel, draft finish or tool change. App holds it as `interacting` state; the new pure helper `shouldScheduleAutosave` (src/editor/autosave.ts, tests in autosave.test.ts) blocks scheduling while it is true. The debounce effect depends on `interacting`, so the 2 s timer is rescheduled when the gesture ends. Checked by unit test plus type check; not exercised in a browser.
2. Host check: `checkGuards` now also requires the Host (or :authority) hostname to be localhost, 127.0.0.1 or [::1] (any port), else 403, via the new `isLoopbackHost`. Tests added for localhost, 127.0.0.1, [::1], evil.example, a missing host, and a few more rejected cases.
