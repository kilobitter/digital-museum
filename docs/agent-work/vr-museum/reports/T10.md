## Decisions
- Arrow nudges: a burst on the same selection is ONE undo step (history key `nudge.<selection nonce>`; changing the selection starts a new step). Arrows only act with the Select tool and ignore works-only selections.
- Duplicate: returned selection holds walls, zones, areas and lone work copies; works that came along with a copied wall are not listed (they follow their wall), so duplicating one wall or one area leaves a single-item selection and the usual inspector. A lone work copy is skipped when it would not fit OR when the offset has no component along its wall (it would sit exactly on the original).
- cutDoorway: if only one piece survives it keeps the original id; if both pieces would be dropped (wall only just longer than the door) it returns an error instead of deleting the wall.
- A lone area selected on the Build layer (via box) shows the multi inspector ("1 area"); the single area inspector stays Areas-layer only. Dragging inside a selected area on Build moves it (areas are not click-pickable there).
- Group drag snaps to the grid only (no wall-line snapping for areas, unlike single area drag).
- Selected works whose wall is not selected do not move in a group drag, nor rotate.
