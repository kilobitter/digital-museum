## Changes
- src/editor/libraryLayout.ts (new): pure helpers: clampLibHeight/maxLibHeight (min 176, max 75% of window, canvas >= 150 px), largeLibHeight/toggleLibHeight (default <-> ~60%), parseLibHeight (localStorage value, null if invalid), gridColumns, gridWindow (row-aligned first/last index with overscan), shouldUseGrid.
- src/editor/libraryLayout.test.ts (new): 8 tests for the above.
- src/editor/LibraryResizer.tsx (new): useLibraryHeight hook (persisted preference in localStorage key `museum-editor-library-height`, try/catch, re-clamped on window resize without losing the preference) and the LibraryResizer separator (pointer capture, body class `lib-resizing` to stop text selection, double-click toggle, ArrowUp/ArrowDown 24 px, Home/End, aria-valuenow/min/max, role=separator, aria-orientation=horizontal).

Taller: vertical grid (columns = floor(width/158), fixed-height cards, row-virtualised with spacer padding). Per-tab scroll offsets (left and top) are saved/restored on tab switch; resets on search/filter change; resets when the mode flips. Search, filter, random-hang, drop zones, progress, selection untouched.
- src/editor/styles.css: grid row uses `var(--lib-h, 176px)`; `.lib-resizer` styles (row-resize, accent hover/focus/active line); grid styles.
- Canvas.tsx not changed: it already measures itself with a ResizeObserver (Canvas.tsx:120), so its viewport, pan/zoom and hit-testing follow the new size. The resizer is a sibling in the library grid cell (not inside the canvas) and captures the pointer, so canvas tools are not triggered.
