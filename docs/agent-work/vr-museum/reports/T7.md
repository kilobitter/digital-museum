## Stacking and draw calls
Each quad carries its own height: floor area at layer index * 1 mm above the floor, ceiling area at the same below the ceiling (array order = height). Because depth decides, all quads with the same finish merge into ONE mesh per surface regardless of interleaving. Area materials use polygonOffset -1, base floor/ceiling +1, so areas never fight the base. Draw calls: 2 (base floor, ceiling) + one per distinct area finish per surface. Worst case = number of distinct finishes used by areas (not walls/works). Stress museum: 5 + 3 + 2 = 10 meshes.
